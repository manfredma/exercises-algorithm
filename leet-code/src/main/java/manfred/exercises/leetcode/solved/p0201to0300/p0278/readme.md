# 第一个错误的版本

你是产品经理，目前正在带领团队开发新产品。不幸的是，产品的最新版本没有通过质量检测。
由于每个版本都基于之前的版本开发，错误版本之后的所有版本都是错误的。

假设有 `n` 个版本 `[1, 2, ..., n]`，请找出导致之后所有版本出错的第一个错误版本。

可以调用 `isBadVersion(version)` 接口判断版本号 `version` 是否错误。实现函数查找第一个错误版本，并尽量减少 API 调用次数。

## 示例 1：

```text
输入：n = 5, bad = 4
输出：4
解释：
调用 isBadVersion(3) -> false
调用 isBadVersion(5) -> true
调用 isBadVersion(4) -> true
所以，4 是第一个错误的版本。
```

## 示例 2：

```text
输入：n = 1, bad = 1
输出：1
```

## 提示：

- `1 <= bad <= n <= 2^31 - 1`
