# 2542. 最大子序列的分数

给你两个下标从 `0` 开始的整数数组 `nums1` 和 `nums2`，两者长度都是 `n`，再给你一个正整数 `k`。你必须从 `nums1` 中选一个长度为 `k` 的子序列。

对于选择的下标 `i0`、`i1`、…、`ik - 1`，你的分数定义如下：

- `nums1` 中所有选中元素之和乘以 `nums2` 中所有选中元素中的最小值。

用公式表示为：`(nums1[i0] + nums1[i1] + ... + nums1[ik - 1]) * min(nums2[i0], nums2[i1], ... ,nums2[ik - 1])`。

返回最大可能的分数。

一个数组的子序列是通过删除一些（可能不删除）元素并保持剩余元素顺序得到的数组。

## 示例 1

```text
输入：nums1 = [1,3,3,2], nums2 = [2,1,3,4], k = 3
输出：12
解释：选中的下标为 0、2 和 3，分数为 (1 + 3 + 2) * min(2, 3, 4) = 12。
```

## 示例 2

```text
输入：nums1 = [4,2,3,1,1], nums2 = [7,5,10,9,6], k = 1
输出：30
解释：选中的下标为 2，分数为 3 * 10 = 30。
```

## 提示

- `n == nums1.length == nums2.length`
- `1 <= n <= 10^5`
- `0 <= nums1[i], nums2[j] <= 10^5`
- `1 <= k <= n`
