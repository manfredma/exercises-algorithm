# 2462. 雇佣 K 位工人的总代价

给你一个下标从 `0` 开始的整数数组 `costs`，其中 `costs[i]` 是雇佣第 `i` 位工人的代价。

同时给你两个整数 `k` 和 `candidates`。我们想根据以下规则恰好雇佣 `k` 位工人：

- 总共进行 `k` 轮雇佣，且每一轮恰好雇佣一位工人。
- 在每一轮雇佣中，从最前面 `candidates` 位工人或者最后面 `candidates` 位工人中选出代价最小的一位工人。如果有多位代价相同的工人，优先雇佣下标更小的工人。
- 例如，`costs = [3,2,7,7,1,2]` 且 `candidates = 2`，第一轮从下标 `0,1,4,5` 中选择下标 `4` 的工人；第二轮从下标 `0,1,3,5` 中选择下标 `1` 的工人。
- 如果剩下的工人不足 `candidates` 位，则从所有剩下的工人中选择代价最小的一位工人。若代价相同，选择下标更小的工人。

一位工人只能被选择一次。

返回雇佣恰好 `k` 位工人的总代价。

## 示例 1

```text
输入：costs = [17,12,10,2,7,2,11,20,8], k = 3, candidates = 4
输出：11
解释：第一轮选择下标 3，第二轮选择下标 5，第三轮选择下标 4；总代价为 2 + 2 + 7 = 11。
```

## 示例 2

```text
输入：costs = [1,2,4,1], k = 3, candidates = 3
输出：4
解释：第一轮选择下标 0，第二轮选择下标 3，第三轮选择下标 1；总代价为 1 + 1 + 2 = 4。
```

## 提示

- `1 <= costs.length <= 10^5`
- `1 <= costs[i] <= 10^5`
- `1 <= k, candidates <= costs.length`
