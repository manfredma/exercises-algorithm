# 重排链表

> 题目链接：[LeetCode 中文站](https://leetcode.cn/problems/reorder-list/)

给定一个单链表 L 的头节点 head ，单链表 L 表示为：
L₀ → L₁ → … → L_n - 1 → Lₙ
请将其重新排列后变为：
L₀ → Lₙ → L₁ → L_n - 1 → L₂ → L_n - 2 → …
不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

## 示例 1

```text
输入：head = [1,2,3,4]
输出：[1,4,2,3]
```

## 示例 2

```text
输入：head = [1,2,3,4,5]
输出：[1,5,2,4,3]
```

## 提示

- 链表的长度范围为 [1, 5 * 10^4]
- 1 <= node.val <= 1000
