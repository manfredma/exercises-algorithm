# 比特位计数

> 题目链接：[LeetCode 中文站](https://leetcode.cn/problems/counting-bits/)


给你一个整数 `n`，对于 `0 <= i <= n` 中的每个 `i`，计算其二进制表示中 `1` 的个数，返回长度为 `n + 1` 的数组 `ans`。不要使用内置函数。

## 示例 1：

```text
输入：n = 2
输出：[0,1,1]
```

## 示例 2：

```text
输入：n = 5
输出：[0,1,1,2,1,2]
```

## 提示：

- `0 <= n <= 10^5`

> 进阶：能否在线性时间复杂度 `O(n)` 内用一趟扫描解决？
