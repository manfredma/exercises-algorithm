# 独一无二的出现次数

> 题目链接：[LeetCode 中文站](https://leetcode.cn/problems/unique-number-of-occurrences/)


给你一个整数数组 `arr`，如果每个数的出现次数都是独一无二的，就返回 `true`；否则返回 `false`。

## 示例 1：

```text
输入：arr = [1,2,2,1,1,3]
输出：true
```

## 示例 2：

```text
输入：arr = [1,2]
输出：false
```

## 示例 3：

```text
输入：arr = [-3,0,1,-3,1,1,1,-3,10,0]
输出：true
```

## 提示：

- `1 <= arr.length <= 1000`
- `-1000 <= arr[i] <= 1000`
