# 二叉搜索树中的搜索

给定二叉搜索树（BST）的根节点 `root` 和整数值 `val`。找到节点值等于 `val` 的节点，返回以该节点为根的子树；节点不存在则返回 `null`。

![](images/tree1.jpg)
![](images/tree2.jpg)

## 示例 1：

```text
输入：root = [4,2,7,1,3], val = 2
输出：[2,1,3]
```

## 示例 2：

```text
输入：root = [4,2,7,1,3], val = 5
输出：[]
```

## 提示：

- 树中节点数在 `[1, 5000]` 范围内
- `root` 是二叉搜索树
- `1 <= Node.val, val <= 10^7`
