# Excel 表列名称

> 题目链接：[LeetCode 中文站](https://leetcode.cn/problems/excel-sheet-column-title/)

给你一个整数 columnNumber ，返回它在 Excel 表中相对应的列名称。
例如：
A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28 
...

## 示例 1

```text
输入：columnNumber = 1
输出："A"
```

## 示例 2

```text
输入：columnNumber = 28
输出："AB"
```

## 示例 3

```text
输入：columnNumber = 701
输出："ZY"
```

## 示例 4

```text
输入：columnNumber = 2147483647
输出："FXSHRXW"
```

## 提示

- 1 <= columnNumber <= 2^31 - 1
