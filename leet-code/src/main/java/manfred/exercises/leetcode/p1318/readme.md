# 1318. 或运算的最小翻转次数

给你三个正整数 `a`、`b` 和 `c`。

你可以对 `a` 和 `b` 的二进制表示进行任意次翻转操作。每次翻转操作的意思是，改变一个数的二进制表示中的一个位，使 `0` 变成 `1`，或者使 `1` 变成 `0`。

返回能够使 `a OR b == c` 成立的最小翻转次数。

## 示例 1

```text
输入：a = 2, b = 6, c = 5
输出：3
解释：翻转后，a = 1，b = 4，c = 5；a OR b == c。
```

## 示例 2

```text
输入：a = 4, b = 2, c = 7
输出：1
```

## 示例 3

```text
输入：a = 1, b = 2, c = 3
输出：0
```

## 提示

- `1 <= a, b, c <= 10^9`
